## 4. 電源ラッチの数値確認

- **保持時間**
  - Q1 が切れるまでの時間は、およそ 時定数 × ln((電池電圧 − 0.3) / |Vgs(th)|) です。
  - 22µF（1608, 10V）は 4V をかけると実容量が約 8µF 程度まで下がると見て、時定数は 100k × 約 8µF ≒ 0.8 秒です。
  - 最悪の組み合わせ（Vgs(th) = −1.1V、電池 3.5V）で約 0.85 秒です。ESP32-S3 が起動してファームが IO2 を H にするまで（数百 ms）は持つ計算です。
  - 足りなければ、C4 を 2 個並列にするか、R4 を大きくします。
- **ボタンの電流**
  - SW1 に流れるのは約 40µA と、IO7 の内部プルアップ分です。TVDP01-095BB1 の最小定格（1V・10µA）を満たしています。
- **SW2 の電流**
  - SW2 にはラッチの戻り電流（µA 程度）しか流れないので、定格 0.3A に十分余裕があります。
- **IO7 の耐圧**
  - ボタンを押していないとき、D4 のカソードは電池電圧近くまで上がります。IO7 側のダイオードは逆向きにかかるだけなので、IO7 に 3.3V を超える電圧はかかりません。

   - 出力ピン：IO2 = 電源の保持（H で保持、L で切る）。

   - SW2 が OFF のときは、ボタンを読めません。ボタンの戻り線が SW2 を通っているためです。
   - **電源を切るときの注意（机上の検討で、実機では未確認）**
     - IO2 を L にしても、Q1 のゲートは R4 100k × C4 22µF（時定数は公称値で約 2.2 秒）でゆっくり上がります。その間 Q1 は半開きになり、VBAT_SW が少しずつ下がります。

     - ファームでの対策案は 2 つです。(1) IO2 を L にしたら、すぐにディープスリープに入る（IO2 は L のまま保持する）。(2) 起動時にリセットの理由を見て、電圧低下によるリセットなら IO2 を H にしない。
     - 実機では、電源を切る操作を何度か繰り返して、確実に切れるか確かめてください。切れないことがあれば C4 を小さくします。その分、短押しで電源が入る余裕は減ります。
   - **SW2 の挙動（故障ではありません）**
     - SW2 を OFF にしてすぐ ON に戻したときは、C4 に電荷が残っているので電源は入りません。ボタンを押してください。
     - 長く OFF にしたあとは、ON にしただけで電源が入ることがあります。

### 12.2 J6 がなくてよい理由（モジュールの回路図で確認）
- モジュールの USB-C の VBUS は、ダイオード B5819WS を通ってモジュールの 5V ピンに出ています。5V ピンはシールド基板の VIN（充電 IC の入力）なので、モジュールの USB-C に挿せば電池が充電されます。ダイオードの分だけ電圧が下がり、充電 IC の入力は約 4.6V になります。4.2V まで充電するのには足ります。
- モジュールの USB-C の CC1・CC2 には、5.1k のプルダウン抵抗がそれぞれ付いています。C-to-C ケーブルでも 5V が来ます。
- 書き込みとシリアル出力は、ESP32-S3 が内蔵する USB で行えます。TX・RX は使いません。
- モジュールの USB-C は、基板の左端（x ≒ 130）から左向きに口が出ます。ケースの左側面に穴が必要です。

### 12.3 USB を挿すと ESP32 が起動する（回路の性質）
USB の 5V は、電源ラッチを通らずにモジュールの 5V ラインへ直接入ります。そのため、USB を挿すと、SW2 やラッチの状態にかかわらず ESP32 が起動します。ハードでは止められないので、ファームで「消えている」状態にします（方式 A、ユーザー了承済み）。

赤・緑の充電表示 LED は充電 IC が直接点けるので、ファームからは制御できません。

### 12.4 ファームの動き（11/15 午後に書き直し。IO4 と IO5 を読む方式）

ファームは、IO4（SW2 の状態）と IO5（USB の有無）を読んで、次のとおりに動かします。前の版の「IO1 がほぼ 0V なら USB だけで起動した」という判定は使いません。

| USB | SW2 | 動き |
|---|---|---|
| あり | OFF | マトリクスを消す（充電だけ）。IO2 は L のまま、IO4 が L になったら目覚めるようにしてディープスリープに入る |
| あり | ON | マトリクスを点ける。IO2 を H にする（USB を抜いても電池で動き続けるため） |
| なし | ON | 電池で動く。ボタンで起動し、IO2 を H にして保持する。操作がなければ IO2 を L にして自分で切れる |
| なし | OFF | 電源が切れている（ESP32 は動いていない） |

**読み方**
- **SW2（IO4）**：内部プルアップで読みます。L なら ON、H なら OFF です。IO4 は RTC GPIO なので、ディープスリープからの復帰にも使えます。
- **USB（IO5）**：VIN の半分が入ります。VIN は、USB ありなら約 4.6V（モジュール上のダイオードの分だけ下がる）、電池で動いているなら「電池電圧 − 約 0.3V」（D3 の分）です。そのため、次の判定で USB の有無が分かります。
  - `VIN（IO5 × 2）> 電池電圧（IO1 × 2）+ 0.15V` なら USB あり。
  - ラッチが切れていると IO1 はほぼ 0V になりますが、この判定はそのままで正しく働きます。
  - IO5 のフィルタは 50kΩ × 100nF ≒ 5ms なので、USB を抜くとすぐに読み値が変わります。

**注意**
- **USB あり＋OFF で IO2 を H にしないこと**：H にすると、USB を抜いたあとも電池で動き続けます。
- **USB あり＋OFF から ON にしたとき**：C4 を通して Q1 のゲートが一瞬下がり、電源ラッチが入ります。ファームは IO4 の L で目覚めて IO2 を H にします。
- **電池で動いている途中で SW2 を OFF にしたとき**：ラッチの戻り線が切れ、C4 の放電のあと（数秒以内）に電源が落ちます。IO4 が H になったのを見て、必要なら設定を保存してください。
- **ボタン**：SW2 が OFF のときは読めません。ボタンの戻り線が SW2 を通っているためです。
- 充電しながら使っている間、本体の電力は USB から来ます。D3 には逆向きの電圧がかかるので、電池からは流れません。充電は続き、満充電の判定も正しく働きます。
- 使っている途中で USB を抜くと、D3 を通して電池からの供給に切り替わります。リセットせずに切り替わるはずですが、実機で確認してください。
- 本体と充電の電流は、合わせて USB から取ります（充電 約 0.2A ＋ ESP32 約 0.1A ＋ マトリクス）。500mA しか出さない電源もあるので、充電中はマトリクスを暗めにしてください。
- ディープスリープ中は USB 経由の書き込みが止まります。書き込むときは、モジュールの BOOT ボタンを押しながら USB を挿します。
- ここに書いた動作は、回路を見た机上の検討です。実機ではまだ確かめていません。

**D4・D5 に 1N4148W を選んだ理由**（データシートの数値は `datasheet/[107084]1N4148W.pdf`）
- ESP32 の電源が切れているとき、D5 には電池電圧が逆向きにかかります。D5 の漏れ電流は R4（100k）を通って Q1 のゲートを下げるので、ここは漏れ電流の小さい部品でないといけません。
- 1N4148W の逆電流は、最大 25nA（20V、25℃）、最大 30µA（25V、150℃）です。75℃程度ならサブ µA で、R4 での電圧降下は 0.1V 未満です。
- 比較：SS14 は 25℃で約 1µA、75℃で約 40µA（漏れで Q1 が開くおそれがある）。BAT43 は最大 0.5µA（25V、25℃）、100℃で 100µA。
- 順電圧は最大 0.715V（1mA）です。ボタンを押したときの IO7 は、約 70µA（内部プルアップ）で 0.5V 前後、R8 の分（0.07V）を足しても 0.6V 前後です。ESP32-S3 の L の上限（約 0.82V）より低いので、L と読めます。
- 確定版の「IO7 側はショットキーを優先」とは違う選び方です。漏れ電流が問題になるのは、まさに IO7 側（D5）なので、シリコンの 1N4148W を選びました。寒いと順電圧が上がるので、実機で、押したときに L と読めるかを確かめてください。
